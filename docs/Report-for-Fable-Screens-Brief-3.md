## Notes and questions

1. **Where the toolkit lives.** The game has no teacher PIN and no pupil profiles yet, so test mode sits in the teacher panel's Testing section, which opens with Ctrl+Shift+T or three taps in the top-left corner. If a PIN is wanted, that is a small addition. Either the plan changed during the week (a change from the board), or the plan Bertie was looking at was the next week's, edited after the review. Nothing else adds a route to the list. If his save code turns up, I can say which.
